## 자주 헷갈렸던 것 / 재발 방지 메모

- **CSS/JS 파일을 고칠 때마다 `?v=YYYYMMDDx` 캐시 버전을 반드시 올려야 함** — 오늘 `i18n.js` 버전을
  안 올려서 새 번역 키가 브라우저에 안 보이는 사고가 한 번 있었음 (고침).
- Supabase 새 API 키 체계에서 **Direct connection = IPv6 기본, Session pooler = IPv4 가능**.
  GitHub Actions는 IPv4만 되므로 pooler 필수, 유저명도 `postgres.프로젝트참조` 형식이어야 함.
- `pg_dump`는 자기보다 **최신 버전 서버**를 거부함 — 서버 버전에 맞추거나 넉넉히 최신으로.
- GitHub Actions `if:` 조건절에서 `secrets.X` 컨텍스트 직접 참조가 파서 에러 남 — env로 받아서
  스크립트 안에서 체크해야 함.
- 방문자 IP/이메일 등 민감정보가 DB에 있으므로 **백업 파일은 절대 공개 저장소에 커밋 금지**.
